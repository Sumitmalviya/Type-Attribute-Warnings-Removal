# 🧹 Type Attribute Warnings Removal (W3C)

Remove deprecated `type` attributes from `<script>` and `<style>` tags generated by WordPress and fix W3C validation warnings — automatically.

---

## 📌 Overview

**Type Attribute Warnings Removal** is a lightweight WordPress plugin that removes unnecessary and deprecated `type` attributes from `script` and `style` tags added by WordPress.

Modern HTML standards (HTML5) no longer require these attributes, and their presence can trigger **W3C validation warnings**. This plugin helps you:

- ✅ Clean up W3C validator warnings
- 🚀 Improve SEO & code quality
- 📐 Follow modern HTML5 standards
- ⚡ Improve perceived load cleanliness (no deprecated markup)

---

## ✨ Features

- 🧼 Removes `type="text/javascript"` from `<script>` tags
- 🧼 Removes `type="text/css"` from `<style>` tags
- 📏 Makes your site more **W3C compliant**
- 🔍 Helps reduce SEO-related validation warnings
- ⚙️ No settings required
- 💡 Works automatically after activation

---

## 🔧 How It Works

The plugin hooks into WordPress’s script and style loader and strips deprecated `type` attributes from the generated markup.

Once activated, it works silently in the background — no configuration needed.

---

## 📦 Installation

### From WordPress Dashboard

1. Log in to your **WordPress Admin Panel**
2. Go to **Plugins → Add New**
3. Search for **Type Attribute Warnings Removal**
4. Click **Install Now**
5. Click **Activate**

### Manual Installation

1. Upload the `w3c-type-warnings` folder to  
   `/wp-content/plugins/`
2. Activate the plugin via **Plugins → Installed Plugins**

🎉 That’s it! The plugin starts working immediately.

---

## ❓ Frequently Asked Questions

### How does this plugin remove W3C warnings?

The plugin uses built-in WordPress hooks to remove deprecated `type` attributes from script and style tags, eliminating related W3C warnings.

---

### Why do these warnings appear on my website?

These warnings occur because:
- HTML5 no longer requires `type` attributes
- WordPress or older themes/plugins still output deprecated markup
- The site may be using outdated coding standards

---

### How can I check W3C validation warnings?

Use the official W3C Validator tool:

🔗 https://validator.w3.org/nu/

Paste your website URL and review errors and warnings.
